# Correccion_prueba
Sistema de Drones en Java

Proyecto básico en Java aplicando Programación Orientada a Objetos.

Características
Clase abstracta Drones
Herencia con:
DroneLiviano
DroneCarga
DroneEmergencia
Uso de polimorfismo
Validación de datos
Cálculo de costos de entrega

Conceptos aplicados
Herencia
Encapsulamiento
Métodos abstractos
Sobrescritura (@Override)
Polimorfismo
